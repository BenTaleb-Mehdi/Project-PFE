# 🎨 VISUAL IDENTITY (THE LIGHT SPEC)

## Backgrounds
- **Primary:** Pure White `#FFFFFF`.
- **Offset:** Zinc-50 `#FAFAFA`.

## Borders
- **Strict:** 1px solid `#E4E4E7` (Zinc-200). Fully compatible with Preline's default Zinc palette.
- **Geometry:** **NO ROUNDED CORNERS** (`rounded-none`). Global hard-edge reset.

## Accents
- **Primary Branding:** Cyan-600 `#0891B2`.
- **Data Metrics:** Cyan-700 `#0E7490` (Forces high contrast on data points).
- **Success:** Emerald-600 `#059669`.

## Typography
- **Labels/Prose:** `font-sans` (Zinc-900).
- **Metric/Macros/IDs:** `font-mono` (Cyan-700) using **JetBrains Mono**.
- **Uppercase Headers:** Must use **`tracking-tight`** (H1, H2, Section Titles).
