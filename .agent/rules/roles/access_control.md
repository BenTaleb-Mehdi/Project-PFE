# 🔐 ACCESS CONTROL ROLES

## ADMIN (COACH)
- Scope: Full Dashboard, Team Management, Finance.
- Permissions: All modules including system settings.

## STAFF (CO-COACH)
- Scope: Client Folders, Nutrition Engine.
- Permissions: CRUD on Nutrition and Clients. **NO FINANCE ACCESS**.

## CLIENT (PUPIL)
- Scope: Personal Progress Tracker, Program View.
- Permissions: Read-only for Programs. Personal data input only.
