# 🎨 V3 VISUAL ENGINE SKILLS

## 📐 GEOMETRY & LAYOUT
- **Protocol:** Strict `rounded-none` enforcement.
- **Micro-shadows:** Application of hard elevation (`shadow-[4px_4px_0px_0px_rgba(0,0,0,0.05)]`).
- **Borders:** Standardization of `ag-border` (Zinc-200).

## 🖋️ TYPOGRAPHY & COLOR
- **Headers:** Force `tracking-tight` on all uppercase H1/H2.
- **Metrics:** Force `font-mono` and `Cyan-700` for all numeric values.
- **Accents:** Intelligent use of `Cyan-600` for primary branding.
